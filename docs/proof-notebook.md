# Use the proof notebook

1. In **Practice**, choose a **Lesson to prove**. A lesson's **Write your own proof** button opens the same notebook before its complete proof. Learn also offers **Open proof notebook**.
2. Write **Your whole argument**. Open conditions, definitions, strategy, paragraph cues, or **Read the source proof now** whenever useful. You can compare an empty page.
3. Choose **Compare with source**. The notebook keeps an unchanged copy beside the exact authored proof. Open **Why this step works** for each paragraph's explanation.
4. Write **What will you keep or change?** Your argument can take a different valid route. The notebook does not grade correctness or establish mastery.
5. Choose **Revise this argument** to edit a copy, or **New blank attempt** to start over. Both retain the capture and reflection under **Earlier captured attempts**.
6. Choose **Show Markdown export** to select and copy the text, or **Download Markdown**. Both include the same exact writing, reflections, authored proof, source note, and canonical lesson locator. If your browser does not save the file, copy the displayed Markdown.

Writing stays in memory in the current tab through lesson changes and in-app navigation. A reload or closed tab clears every notebook. No sign-in is needed. Notebook writing does not change account lesson marks. Use **Read this lesson** to visit the lesson without reloading the tab.

**Reset this lesson notebook** asks for confirmation and clears that lesson's attempts and reflections. **Cancel** or Escape keeps them. Other lesson notebooks remain intact. Export first to keep a copy.

A URL such as `/practice?proof=D04#proof-notebook` selects a lesson without carrying writing. An unknown ID shows recovery guidance and a button to open the first lesson notebook.
