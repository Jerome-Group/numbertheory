# Publish owned number theory learning source under MIT

The Owner wants a public Number Theory learning website like the Algebra and Calculus sites.
Students and educators should be able to inspect, run, adapt, and share its owned source and
educational material. MIT grants those rights. This replaces the template's all-rights-reserved
placeholder for this project only; dependencies and third-party assets keep their own terms.

The public repository may contain owned application source, explanations, examples, and assets.
Credentials, private notes, student data, authenticated browser state, course files, and
unlicensed third-party material stay outside its tree and history. Access-controlled course
resources may be linked, but their sharing permissions continue to govern access. Ignore rules
exclude common course-document formats and private material directories before application
source is added.

The repository currently contains its foundation, not the website application. Add build and
test instructions when application source arrives.
