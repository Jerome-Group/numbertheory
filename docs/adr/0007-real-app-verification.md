# ADR 0007: Verify user behavior on an owned app

Status: accepted, 2026-10-18.

Passing mathematical and source contracts missed two browser failures: malformed experiment URLs crashed rendering, and changing continued-fraction depth remounted the focused slider. Keep exact arithmetic and integrity contracts, and add real browser journeys for user behavior.

One public agent CLI exposes strict syntax, effects and JSON outcomes. Its internal command registry owns discovery and dispatch. The project verification skill owns feature recipes and browser helpers, so maintenance can repair its own driver without adding test controls to the product. Launch is a foreground owned process. Receipts permit cleanup after interruption only when process identity still matches.

The feature map follows source-owned lessons, paths, labs and controls. Run one built app and serial journeys with fresh browser contexts. Retain failed attempts, traces and actual artifact digests outside this public repository. CI uses the same commands and uploads scoped evidence on failure.

Scoped Playwright evidence does not satisfy the exhaustive native in-app-browser or independent mathematical review contracts. Those retain separate formats and freshness checks. Unknown coverage and missing prerequisites stay explicit. A finite verification suite cannot promise complete correctness.

Prefer observed behavior to simulated framework internals. Test-first development is optional. Before removing a redundant harness, show that its browser replacement fails on a known bad implementation and passes the repair. Keep the shared source loader and avoid repeating content/type gates during the asset build; standalone builds still run their prerequisites.

The drawer replacement catches a deliberate focus-restoration mutation and additionally found a real Back-navigation race. Coordinate the drawer's inert/focus cleanup and destination focus before repaint. A build receipt records source and lock hashes after a successful build with unchanged inputs, so a current source fingerprint cannot relabel an older bundle.
