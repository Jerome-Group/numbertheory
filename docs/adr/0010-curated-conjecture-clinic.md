# ADR 0010: Curated finite investigations in Studio

Status: accepted.

Conjecture Clinic joins Studio with five curated claims and three hypothesis choices per claim. Each full search has fixed bounds, a deterministic first counterexample, and explicit admitted, premise-true, and counterexample counts. The polynomial investigation fixes x²−1. The Jacobi investigation tests a converse, with its prime repair linked to Q01 and its writing linked to Q06.

A condition changes the universal claim’s domain. Keeping one witness lets a learner see that exclusion changes admission while the arithmetic stays fixed. Independent count and certificate oracles check the exact mathematics. Browser journeys establish navigation and interaction separately. Finite success earns no correctness, proof, or mastery mark. The supplied repair is sufficient and need not be the weakest repair.

The existing study store owns configuration, searched state, and the case-keyed kept witnesses. Reports derive from that configuration. Search replaces the current history entry; a changed case or condition pushes an entry. Entry and browser history focus the Clinic heading, while controls retain focus during selection and search. Shared configuration recomputes exact evidence on reload. Kept witnesses remain tab-local across in-app navigation and clear on reload, like the existing proof notebook’s writing boundary. They do not enter account progress or URL data.

A free expression language would require syntax, supported domains, solver limits, and new proof obligations before a learner could test a claim. Fixed families keep the mathematical decision visible. Variable bounds, multiple-witness browsing, prediction, and a second writing or export workspace add controls without serving the first investigation. Authored proofs and the existing notebook already carry the next step.

Revisit the fixed families when a new lesson needs an exact, independently verifiable investigation. Revisit storage only with an explicit learner-owned persistence design.
