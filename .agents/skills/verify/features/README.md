# Number Theory verification map

Run the real built Worker and local D1 through [the skill](../SKILL.md). Five domains share one owned instance and use fresh browser contexts. Read-only cases are anonymous. Per-lesson teaching cases use invented local identities throughout, as do marking and account cases. Evidence goes to a new absolute directory outside the repository. The script derives lesson, path, checkpoint, view, and lab records from the existing verification map and source loader. Do not maintain a second ID inventory here.

| Domain | User outcomes | Driver feature |
| --- | --- | --- |
| [Discovery](discovery.md) | All six views, diagnostic, search, paths, checkpoints, reference, course | `discovery` |
| [Teaching](teaching.md) | All 83 lessons, canonical and legacy entries, proof annotations, reasoning, practice | `teaching` |
| [Practice and progress](practice.md), [proof notebook](proof-notebook.md) | Tab-only whole arguments, source comparison, revision, exact Markdown export, plus acknowledged account marks, D1 isolation, transfer and recovery | `practice` |
| [Exact labs](labs.md), [Conjecture Clinic](conjecture-clinic.md) | All 20 lab entries across 14 types, plus five claims with complete searches, exact witnesses and repairs | `labs` |
| [URLs and native tools](urls.md) | Shared inputs, history, malformed URL recovery, drawer and keyboard, optional native WebMCP | `urls` |

Each feature document has exactly four H2s. `Preconditions` names any required state. Capture actions and asserted results, plus screenshots, DOM, ARIA, traces, and exact identity. A missing precondition is not a pass through another entry point. The report lists all existing coverage obligations, including those requiring independent browser or mathematical review.

Three viewport profiles run for every domain. Phone and tablet also run drawer journeys. Current automation uses reduced motion. Forced colors, print, extra viewport widths, native accessibility inspection, native browser storage policy, native tools, semantics, and production need separate evidence. Actual Sites sign-in and sign-out roundtrips and two real hosted accounts remain unverified locally. Keep those report rows not-evaluated until observed.

The older-data account journey injects a storage-read SecurityError and corrupt JSON into an isolated local fixture. It checks application recovery and preservation of original bytes and account marks. This does not establish native browser storage-policy enforcement.
